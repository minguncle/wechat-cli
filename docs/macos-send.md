# Mac 界面文字发送

需要宿主提供 Mac 界面工具和相应权限；这不是包内 CLI send 后端。旧 AppleScript 尚未完成当前微信版本的独立 CLI 实测，不能拿它代替已验证入口。

1. 按用户允许的方式工作。用户限制原生后台时说明本版尚未适配。已允许界面发送时，不重复确认同一目标和内容。
2. 用 CLI 查出稳定 chat_id 和完整名称，确认微信登录来源账号。出现重新登录提示时让用户完成登录，尚未发出的请求不能报成功。
3. 用宿主界面工具检查状态并按工具文档操作，不复用变化前的元素编号。搜索无结果时可清空搜索，滚动会话列表，选择完整名称严格匹配的会话。
4. 同时核对 `current_chat_name_label` 与 `chat_input_field` 指向完整目标名称。群成员数是独立标签，不拼入名称。已有草稿不覆盖。
5. 输入授权正文，重新检查目标和输入框内容，再执行一次发送。宿主提供恢复剪贴板的粘贴接口时优先使用。
6. 重新读取界面，要求目标聊天仍正确、输入框清空且消息列表出现本次正文。记录这是界面发送，不能称为原生后台或 CLI send 已完成。
7. 用 CLI 同步并核对记录。若回读只有撤回提示，可报告发送后出现撤回记录，不能擅自补发。结果不明确时停止，不自动重试。

当前只验证文字；Mac 界面图片、文件发送需要另行验证。界面工具不可用或权限不足时说明阻塞，不悄悄改变系统授权。
